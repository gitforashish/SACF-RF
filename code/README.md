# Source Code

## sacf_rf_baseline_comparison.py

This script implements the proposed SACF-RF framework on the NSL-KDD dataset.

### Workflow

1. Data Preprocessing
2. PCA Representation
3. HMM Operational State Generation
4. Isolation Forest Anomaly Scoring
5. Behavioral Cognition Engines
6. Adaptive Severity Fusion
7. Random Forest Classification
8. Baseline Comparison

### Baselines

* Isolation Forest
* Local Outlier Factor (LOF)
* One-Class SVM
* Random Forest

### Proposed Model

* SACF-RF (State-Aware Cognitive Behavioral Intelligence Framework)
