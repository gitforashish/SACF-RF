# SACF-RF

State-Aware Cognitive Behavioral Intelligence Framework for Cross-Domain Anomaly Detection in Cyber-Physical Systems

## Author

Ashish Kumar
Quantum University, Roorkee

## Overview

SACF-RF is a state-aware anomaly intelligence framework designed for cross-domain anomaly detection in Cyber-Physical Systems. The framework integrates:

* PCA Behavioral Embedding
* HMM Operational-State Cognition
* Isolation Forest Anomaly Reasoning
* Behavioral Cognition Engines
* Adaptive Severity Fusion
* Random Forest Classification

## Datasets

* NSL-KDD
* SWAT
* NASA C-MAPSS
